## Setup (Windows)
1. Install Python 3.12 (tick "Add python.exe to PATH").
2. Double-click `setup_windows.bat` (creates `.venv` and installs everything).
3. Open this folder in VS Code, install the Python + Jupyter extensions, select the `.venv` interpreter/kernel.
